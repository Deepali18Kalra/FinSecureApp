FINSECURE POSTMAN TESTING - QUICK START

================================================================================
1. SETUP DATABASE
================================================================================
Open MySQL Command Line:
  mysql -u root -p
  (enter password: root)

Then run:
  CREATE DATABASE finsecure;

Done!

================================================================================
2. START APPLICATION
================================================================================
Open Command Prompt/PowerShell at: C:\FinSecure\FinSecureApp

Run:
  mvn clean spring-boot:run

Wait until you see:
  "Started FinSecureProjectApplication in X.XXX seconds"
  "Tomcat started on port(s): 8085"

================================================================================
3. IMPORT POSTMAN COLLECTION
================================================================================
Open Postman

Click: File → Import
Or: Ctrl + O

Select: FinSecure-Complete-Testing.postman_collection.json
(From C:\FinSecure\FinSecureApp folder)

Click Import

5. EXPECTED RESULTS
================================================================================

✅ Successful Test:
   Status: 200 OK

❌ Failed Test (No Token):
   Status: 401 Unauthorized or 403 Forbidden

❌ Failed Test (Wrong Password):
   Status: 401 Unauthorized
   Response: Error message about invalid credentials

================================================================================
6. TESTING TIPS
================================================================================

1. Run STEP 1 first (Create Users) - must do once
2. Run STEP 2 (Login) - tokens are saved automatically
3. After STEP 2, you can run any other test in any order
4. Tokens expire in 1 HOUR - if tests fail, run STEP 2 again
5. Check Postman Console for details: View → Show Postman Console
6. Environment variables show in Postman top-right corner

================================================================================
9. TROUBLESHOOTING
================================================================================

Problem: "Unknown database 'finsecure'"
Solution: CREATE DATABASE finsecure;

Problem: "Connection refused"
Solution: Check MySQL is running and app is running on 8085

Problem: "401 Unauthorized on all tests"
Solution: Run login requests again (STEP 2)

Problem: Tests passed before but now fail
Solution: Token expired - run STEP 2 again to get fresh tokens

Problem: "Invalid username or password" on login
Solution: User wasn't created - run STEP 1 again
